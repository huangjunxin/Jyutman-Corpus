# 白话报今译与粤拼音表说明

状态：AI 初译稿，未经人工校订。本文件说明 `translations/` 派生数据的来源、复验结果与待决事项，供编委会与下游消费方使用。

## 数据说明与复验结果

### translations/gdvp.translations.json

- 内容：1907 年《广东白话报》全部 269 篇发布层文章的今译。每篇结构为 `{id, title, paragraphs: [{orig, trans}], notes}`；`orig` 照录发布层原文，`trans` 为粤语口语体今译，`notes` 为译者注（含标题今译与系统性说明）。
- 来源：JyutmanDataPipeline 发布层 `data/gd-vernacular-paper/articles.jsonl`（269 篇）。
- 合并：由 18 个批次文件 `batch-01.json` 至 `batch-18.json` 合并，按 `id` 升序排列；目录中的「batch-XX：第 N 到 M 行.json」双命名副本共 12 组，经 md5 校验与对应主文件一致后忽略。同 id 冲突即报错，本次未出现。
- 分册条数：issue-01 44 篇、issue-02 71 篇、issue-05 73 篇、issue-07 81 篇。
- 规模：1347 段；原文 64948 字符；译文 87649 字符（含标点与就地译注）；译者注 17922 字符。
- 复验：以发布层 `articles.jsonl` 为准，逐篇断言 `'\n\n'.join(paragraphs[*].orig) == text`，269/269 通过，0 篇不一致；译文 id 集合与发布层完全一致，无重复 id。
- 疑注：`〔譯者疑〕` 标记共 987 处（正文 939 处、notes 48 处），涉及 211 篇。

### translations/jyutping/

- 三个语料的粤拼音表：`gd-vernacular-paper.jyutping.json`（269 篇全覆盖）、`canton-vernacular-handbook.jyutping.json`（329 篇）、`readings-in-cantonese-colloquial.jyutping.json`（268 篇）。

- 生成：由 tojyutping 3.2.0 从对应语料的发布层文本生成，属派生数据，未人工校订；随上游发布与校订流程更新。

## 系统性发现摘要

### 跨页 / 跨栏断句普遍

发布层 `text` 以 `\n\n` 连接版面行，断行多来自版面的物理行界（分栏、跨页、栏线），并非语义段落。译文保留同一段落结构以便与原文对读，因此建议下游按标点合并后再渲染，不要逐段独立成段。notes 中明确标注跨页续接、跨栏断句或未完待续者共 49 篇，例如：

- gdvp-02-029-02 末句「佢都可」接 gdvp-02-030-01 首句「以喺個檻裏便嚟嘯」。
- gdvp-05-037-01 与 gdvp-05-038-01 为同一段对话，因跨页分栏而断开。
- gdvp-02-054-02 注：「原文係報紙欄線分行，譯文各段相連即為完整句」。
- gdvp-01-003-01 末段跨页未完，下页 gdvp-01-004-01 接「保戳」。

## 待统一政策：曲 / 南音 / 文言文本的今译体例

各批次对曲本、说唱与文言文本的处理不一致，建议编委会裁定统一体例。现状举例：

- 班本 / 曲本：gdvp-01-029-01 巨戲台（粤剧班本）译作可读粤语并保留板腔标记（首板、慢板）；gdvp-05-042-02 痛定痛（四续）唱词按行译出并保留「（唱）（白）」；gdvp-02-042-02、gdvp-05-046-01（四大害，南音）、gdvp-07-056-02、gdvp-07-059-02、gdvp-07-060-01 等将唱词逐行今译，平仄记号照录。
- 龙舟 / 南音：gdvp-01-035-01 好油喉（南音说唱）「今譯為可讀粵語散文，保留原分段」；gdvp-02-046-01 歎米貴（龍舟歌）保留断句节奏逐行对应。
- 文言：gdvp-01-017-02（文言章回体）今译作粤语口语体；gdvp-07-012-01（文言告示）改现代标点；gdvp-07-020-01（公文引文）改现代标点并翻成粤语。

建议体例（供裁定）：唱词保留曲体，仅现代化用字与标点；文言公文体译为带粤语虚词的公文体，不作口语化改写。

## 翻译工作流说明

- 全部译文由 AI 按每批约 15 篇初译（共 18 批），未经人工校订；疑处就地加 `〔譯者疑〕`，存疑不臆改。
- 本稿为工作稿，正式发布前须经校订流程：人工比对原刊影像、裁定疑注、统一体例。
- 读者界面引用本数据时应醒目标注「未校訂」（即「未校订」）。
- 译文属本站编辑成果，同样适用禁破折号规则：`trans` 与 `notes` 内一律不用破折号（`—` / `——` / `–`），并列分句用「，」、转折语气用「；」或拆句、夹注用「（）」；`orig` 照录底本原文，不受此限。
