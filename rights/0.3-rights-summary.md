## 方法与口径

- 本机检索：JyutmanDataPipeline 的 `work/` 层数字化声明页转录、藏书票与索书号页、`sources/` 原始文件名。
- 在线检索：当前网络无法直连 archive.org（域名解析被污染，真实 IP 亦可疑，443 连接超时），advancedsearch 与 metadata API 均不可达，公共 CORS 代理亦失败。改用公开检索读取 Internet Archive 条目页、下载页、Wikimedia Commons 文件页与 Wikisource 索引页的片段，记录标识符与置信度（确定／疑似／未定位）。
- 判定口径：底本一律按出版年与中美两地版权保护期判定。这批文献出版于 1842 至 1907 年，作者逝世逾 70 年，中国（作者终身加 50 年）与美国（1930 年前出版物）保护期均已届满，属公有领域。
- OCR 文本层许可 CC BY-SA 4.0 是本项目的自定许可，与扫描件条款分属不同层面。
- 影像政策：按 `docs/03` §8，扫描影像在藏馆条款逐件核查完成前不公布；本表服务于文本层发布与日后影像开放审批。
